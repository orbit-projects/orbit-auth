# Orbit Auth roadmap

This roadmap describes possible work; planned items are not implemented features.

## Current

- Provider-neutral authentication and authorization contracts.
- Explicit Basic and bearer authentication implementations.
- Optional `orbit-auth-oauth2`, `orbit-auth-jwt`, and `orbit-auth-rbac` integrations.

## Later

- Installation and compatibility matrix for the Core runtime and auth integrations.
- Reviewed shared token revocation and key-rotation integrations in separately installable packages.
- Hosted CI, package provenance, and release validation.

These items remain unimplemented until their contracts, code, tests, and docs are available.
